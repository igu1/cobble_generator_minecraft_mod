## About This Mod

This Forge-powered mod injects a straightforward **cobblestone generator** into your Minecraft world—no more strip mining required! Place the block, let it work its magic, and watch cobble roll in. Added to Forge versions between 1.16.5 and 1.19.

## Installation Instructions

1. Make sure you’re running **Minecraft Java Edition** with **Forge** installed.  
2. Drop the mod’s `.jar` into your `mods/` folder.  
3. Launch the game with your Forge profile.  
4. Enjoy endless cobblestone—effortlessly.
